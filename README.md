# 戀愛劇情遊戲（網頁版）

點擊推進對白、選項分歧劇情的視覺小說，開場帶一段「探索階段」。
做完之後放上 GitHub Pages，任何人開網址就能玩，不用安裝。

---

## 一、現在就能玩

**在檔案總管裡雙擊 `index.html`** 就會用瀏覽器打開，不需要安裝任何東西。

如果瀏覽器對本機檔案有安全限制（例如存檔按了沒反應），改用這個方式：在專案資料夾開 PowerShell 執行下面這行，然後打開 <http://127.0.0.1:8123/>。

```bash
powershell -File tools/serve.ps1
```

目前可以玩到的內容（共 17 個場景，從頭到尾走得完）：

1. **探索階段** — 校門口，4 個會發光的地方可以點，集滿 3 顆光玉才進入劇情
2. **第 1 幕 中庭長椅** — 三選一分歧（其中一條會走到「挑戰失敗」，可以重選）
3. **第 2 幕** — A／B／C 三條路
4. **第 3 幕 黃昏的空教室** — 三選一分歧
5. **第 4 幕** — A／B／C 三條路
6. **第 5 幕 櫻花飛舞的坡道** — 三選一分歧
7. **第 6 幕** — A／B／C 三條路
8. **第 7 幕 我們的故事由此開始** — 黑幕字卡 → 坡道頂端 → 結尾 CG

右上角有「重選／音樂／自動／回顧／存檔／讀檔」六個按鈕。

**「重選」**會跳回你**最近一次做選擇**的那個畫面，而且**不用重看一次對白**。
好感度、旗標、光玉都會一起還原到當時的狀態，所以反覆重選不會把分數愈加愈高。
還沒做過任何選擇時這顆按鈕是暗的。

## 二、專案結構

```
love_game/
├─ index.html                   ← 遊戲入口，雙擊這個檔案就能玩
├─ story/
│   └─ story.js                 ← ★ 劇本檔，你之後主要要動的就是這個
├─ assets/
│   ├─ characters/              ← 角色立繪（已切好）
│   │   ├─ hero/      16 張半身表情 ＋ pose_stand.png（全身）
│   │   └─ heroine/   16 張半身表情 ＋ pose_stand.png、pose_bag.png（全身抱紙袋）
│   ├─ backgrounds/             ← 背景圖（已有 school_gate_spring.jpg）
│   ├─ props/                   ← 探索場景的物件圖（目前這一幕用不到）
│   ├─ bgm/                     ← 背景音樂（還沒有）
│   ├─ css/style.css            ← 版面樣式
│   └─ js/
│       ├─ engine.js            ← 遊戲引擎
│       └─ effects.js           ← 櫻花、光玉、閃光等特效
├─ data/                        ← 原始大圖，遊戲不會直接讀取
├─ tools/
│   ├─ split_sprites.ps1        ← 把表情大圖切成單張素材
│   ├─ cutout.ps1               ← 把單張白底圖去背
│   ├─ clean_gaps.ps1           ← 清掉髮絲間沒去乾淨的白縫
│   ├─ optimize_bg.ps1          ← 壓縮背景圖
│   ├─ optimize_sprite.ps1      ← 縮小過大的立繪（保留透明）
│   ├─ imagelib.ps1             ← 上面兩個工具共用的程式碼
│   └─ serve.ps1                ← 本機測試用的小型伺服器
└─ README.md
```

素材已經處理好：背景去乾淨（透明），而且 **16 張的臉都對齊在同一個位置**，遊戲切換表情時人物不會跳動。
兩張全身立繪也共用同一條垂直基準線，所以用同一個高度顯示時，男女主的身高差和腳底線都是對的。

### 半身表情 vs 全身立繪

| | 用在哪 | 特點 |
|---|---|---|
| **半身表情** `01_smile.png` … | 角色說話時 | 16 種情緒，臉部特寫 |
| **全身立繪** `pose_stand.png` | 撐場面、探索階段 | 只有一種表情，但看得到全身和站姿 |

引擎會自動在兩者之間切換：探索場景顯示全身立繪，**角色一開口說話就切成半身特寫**（像鏡頭推近），說完再切回全身。你不用管，寫劇本照舊。

## 三、怎麼寫劇本

**你用純文字寫就好，我負責轉成 `story/story.js`。** 下面說明只是讓你知道遊戲能做到哪些事。

### 3-1　一般對話幕

用這個格式寫給我：

```
=== 第1幕：初次搭話 ===
【場景】圖書館・傍晚
【音樂】安靜的午後

旁白：放學後的圖書館幾乎沒人，只剩書架間漂浮的灰塵。
女主(微笑)：「……你也常來這裡嗎？」
男主(緊張)：「偶、偶爾啦。」
女主(害羞)：「那，如果不介意的話，可以告訴我你的名字嗎？」

【選項】
  A. 老實說出名字        → 第2幕A    好感 +1
  B. 假裝沒聽見          → 第2幕B    好感 -1
  C. 反問她的名字        → 第2幕C    好感 +2
```

規則只有這幾條：

- `角色名(表情)：台詞` — 表情用對照表的中文意思寫就行
- `旁白：……` — 沒有人講話的敘述文字
- `【場景】` 決定背景圖，`【音樂】` 決定背景音樂
- 沒有選項的幕，最後寫 `【接下一幕】第X幕`
- 選項要寫清楚三件事：**選項文字 → 跳到哪一幕 → 好感度變化**
- 想讓稱呼改變（`？？？` → `孟格`），在那句後面註明「（之後改叫孟格）」

### 3-2　探索幕

這種幕不是一路點下去，而是**讓玩家在畫面上找東西點**，集滿指定數量的「光玉」才會進入下一幕。

寫給我的格式：

```
=== 第0幕（探索）：校門口 ===
【場景】校門口・春天的早晨
【音樂】春天的風
【櫻花】開          ← 要不要飄櫻花
【需要光玉】3

【開場白】
旁白：四月的風裡，還留著一點冬天沒帶走的涼意。
旁白：我在校門口停下腳步——不是因為遲到，是因為那個站在櫻花樹下、一動也不動的女生。

【可點擊物件】

① 飄落的櫻花枝　位置：左上　特效：花瓣暴風雨　不給光玉、可重複點
   旁白：一陣風掃過樹梢，花瓣整片整片地捲了下來。
   旁白：漫天櫻花下，時間彷彿停滯了……

② 少女胸前的紙袋　位置：少女胸口　給光玉
   旁白：她雙手抱著一個紙袋，抱得很緊，像是怕誰搶走。
   男主(微笑)：「那個……你手上拿的是？」
   女主(害羞)：「……！裡、裡面是紅豆麵包。」
   女主(臉紅慌亂)：「能給我勇氣的食物。」

③ 圍牆邊的塗鴉　位置：左下　特效：糰子圖案　給光玉
   旁白：圍牆的角落，有人用粉筆畫了一排圓滾滾的東西。
   旁白：這是……糰子大家族的圖案？

④ 看板上的貓　位置：糰子看板上面　【隱藏】　不給光玉、可重複點
   旁白：糰子看板的上面，蹲著一隻打扮得莫名隆重的貓。
   男主(困惑)：「……這隻貓好像在哪裡見過。」
   女主(驚訝)：「啊，牠住在這附近喔。大家都叫牠糰子貓。」

⑤ 沉思的少女　位置：少女的臉　給光玉
   旁白：她一直望著校門裡面，卻沒有踏進去。
   男主(緊張)：「……你不進去嗎？」
   女主(驚訝)：「！」
   女主(尷尬)：「……嗯。再一下下就好。」

【集滿之後】
旁白：三件零零碎碎的小事，在心裡串成了一條線。
旁白：我好像，稍微看懂了她一點。
【接下一幕】第1幕
```

遊戲裡實際會發生的事：

- 每個可點擊物件都有**呼吸的光暈 + 往外擴散的漣漪**，玩家一眼就看得到
- 點下去會播那段台詞，播完如果該給光玉，就有一顆光飛到左上角的計數器
- 畫面下方常駐提示「還差 N 顆光玉」
- 已經點過的物件光暈會消失，避免重複點
- 集滿之後畫面閃一下白光，播完結語自動進入下一幕

**標【隱藏】的物件**平常完全不發光，玩家要自己注意到畫面上多了什麼才找得到。
適合放不影響通關的彩蛋，滑鼠移上去才會有一點光暈當回饋。

目前支援的特效：`花瓣暴風雨`、`糰子圖案`、`白光閃爍`。想要別的（例如「物件浮起來」「畫面震動」）跟我說，我加。

**位置**你用文字描述就好（左上、右下、少女的臉……），我來換算座標。

### 3-3　字卡（黑幕標題、結尾畫面）

想在中間插一張只有一句話的畫面，這樣寫：

```
=== 字卡：我們的故事由此開始 ===
【字卡】我們的故事由此開始
【停留】3 秒
【接下一幕】第7幕
```

```
=== 字卡：結尾 ===
【場景】結尾CG
【字卡】TO BE CONTINUED...
【位置】下方
（沒有下一幕，停在這裡收尾）
```

- 沒寫【場景】就是**全黑畫面**，有寫就是那張背景圖加一層讓字看得清楚的暗角
- 【停留】時間到會自動進下一幕，玩家點畫面可以提早跳過
- 沒有【接下一幕】就會停在那張畫面，用來收尾

### 3-4　先寫多少才夠？

建議先寫 **3～5 幕、含一個選項分歧**。我接上去讓你實際玩，你確認手感之後再往下寫，比一次寫完再發現不對勁好很多。

## 四、素材規格

### 4-1　新角色的表情圖

你用 AI 生圖產，規格照下面來，切圖交給我。

- **純白背景**，人物之間不要有陰影、邊框、裝飾線
- **4 欄 × 4 列 = 16 格**，每格一個表情
- 每格都是**同樣的構圖**：半身、正面、臉的位置固定不動
- 解析度至少 1792×2390（每格約 450×600）
- **不要在圖上加任何文字標籤**（像原本那兩張的「怒」「樂」，我得手動擦掉）

提示詞範本（把 `<>` 內換成你要的角色設定）：

```
A 4x4 grid of 16 expression sheet portraits of the same character,
<a cheerful high school boy with messy red hair and a track jacket>,
anime visual novel style, clean cel shading, bust shot, front facing,
identical head position and framing in every cell,
pure white background, no text, no labels, no borders,
expressions in order: smile, laugh, shy blush, troubled,
confused, thinking, surprised, nervous sweat,
crying, sad, angry, neutral,
rage, embarrassed blush, smug grin, deadpan
```

產好之後把圖放進 `data/`（例如 `data/rival_face_express.jpg`），告訴我「這是誰、每格是什麼表情」，我來切。

想自己跑的話，在專案資料夾開 PowerShell：

```bash
powershell -File tools/split_sprites.ps1 -Source data/rival_face_express.jpg -OutDir assets/characters/rival -Names smile,laugh,shy,troubled,confused,thinking,surprised,nervous,crying,sad,angry,neutral,rage,flustered,smirk,deadpan
```

### 4-2　全身立繪

一張角色的全身站姿圖，用來撐探索場景和過場。

- **PNG 透明背景**（純白底或純灰底的圖也行，我有工具去背）
- **全身入鏡**，頭頂到腳底都要在畫面內，不要被裁到
- 正面或稍微側身、**站姿自然**，背景不要有影子或地板
- 高度至少 1500px
- 檔名 `assets/characters/<角色>/pose_<姿勢名>.png`，例如 `pose_stand.png`、`pose_bag.png`
- **姿勢圖還沒放進來也不會壞**，會自動退回該角色的半身表情圖

**目前還缺一張**：第 7 幕孟格轉身微笑那張，請存成
`assets/characters/heroine/pose_turn.png`（透明背景 PNG）。
放進去就會自動生效，現在暫時用微笑的半身圖代替。

同一個角色的多張姿勢圖，**最好在同一張圖裡一起生**（並排），這樣身高比例才會一致；我切開的時候會讓它們共用同一條腳底基準線。

去背指令（在專案資料夾開 PowerShell）：

```bash
powershell -File tools/cutout.ps1 -Source data/stand.jpg -OutDir assets/characters/hero -Name pose_stand -Background Flat -KeepLargest
```

- `-Background Flat` 用在灰底或**棋盤格底**（有些工具會把「透明」直接畫成棋盤格再存成 JPG，那其實不是真的透明）
- `-Background White` 用在純白底（這是預設值，可以省略）
- `-KeepLargest` 只保留最大的一塊圖案，把背景裡沒連到人物的零碎東西（壁畫、樹葉）清掉
- `-MaxChroma 4` 背景是灰階、但圖裡有接近白色的東西（例如白色玩偶）被誤刪時，把這個值調小

**髮絲間的白縫**：去背是從圖的外框往內填，所以被線稿四面包住的白色（頭髮和肩膀之間那條縫）碰不到，會留下白邊。用這個清：

```bash
powershell -File tools/clean_gaps.ps1 -Source assets/characters -WhatIf
```

加 `-WhatIf` 是**試跑**，只列出會刪掉多少、不動檔案。確認數字合理再拿掉 `-WhatIf` 實際執行。
它只刪「離透明區很近＋細長條＋面積夠大」三個條件同時成立的區塊，所以牙齒、眼睛高光、對話泡泡、白衣領都不會被誤刪。

### 4-3　探索場景的物件

探索幕的畫面是**三層疊起來**的。光玉不一定要有自己的圖 —— 只要那個東西已經畫在背景或立繪上，熱區直接對準它就好：

| 層 | 放哪裡 |
|---|---|
| 背景 | `assets/backgrounds/` |
| 角色立繪 | `assets/characters/<角色>/` |
| 場景物件 | `assets/props/` |

**目前這一幕四個光玉都不需要額外素材：**

| 物件 | 素材從哪來 |
|---|---|
| 飄落的櫻花枝 | 背景圖左側的櫻花樹 |
| 圍牆邊的塗鴉 | 背景圖上的糰子大家族看板 |
| 少女胸前的紙袋 | 女主角全身立繪 `pose_bag.png` 上她抱著的紙袋 |
| 沉思的少女 | 同一張立繪的臉 |

**什麼時候才需要 `assets/props/` 的圖？** 當那個東西背景裡沒有、立繪上也沒有的時候。例如「地上的一封信」「窗邊的貓」。這時候：

- **PNG，背景要透明**
- 尺寸抓「在 1280×720 畫面上想佔多大」就對了
- 放進 `assets/props/`，告訴我檔名和位置，我來接上
- **沒放圖也不會壞**，只是只看得到一個光點

熱區的位置和大小如果覺得不對，跟我說「櫻花枝的光點再往下一點」「紙袋的範圍太小不好點」就行，我來調。

### 4-4　背景圖

- 格式 **JPG**，尺寸 **1920×1080**（16:9）
- 放進 `assets/backgrounds/`，檔名用英文，例如 `school_gate_spring.jpg`
- **檔名要和劇本裡的場景 id 一致，放進去就會自動取代目前的色塊，不用改任何程式**
- 單檔別超過 500KB（我可以幫你壓）
- 同一個地點的不同時段（白天／黃昏／夜晚）分開存，氣氛差很多

> **存檔時注意副檔名。** Windows 預設隱藏已知的副檔名，很容易存成 `school_gate_spring.jpg.jpg` 這種雙重副檔名，遊戲就找不到檔案。
> 建議在檔案總管的「檢視」頁籤把「副檔名」打勾，才看得到真正的檔名。

常見要準備的：教室、走廊、圖書館、天台、校門口、街道、咖啡廳、房間、公園。先做劇本裡真的會用到的就好。

### 4-5　音樂與音效

- **背景音樂**：MP3，放 `assets/bgm/`，檔名如 `spring_wind.mp3`
- **音效**：MP3，放 `assets/se/`，例如 `click.mp3`
- 一樣是**檔名對上劇本裡的名稱就會自動生效**
- 會自動循環播放，右上角有「音樂」開關可以靜音

第 5 幕之後都用「糰子大家族」。玩家如果是走第 4 幕 C 過來的，因為解析後是同一個檔案，音樂會**直接接著播下去、不會重播**。

有幾個名稱共用同一個檔案，設定在 `story.js` 的 `BGM_ALIAS`。這樣除了少放幾份檔案，**同一首在連續兩幕之間會接著播下去，不會從頭重來**。之後想讓某一幕換成自己的曲子，把對應檔名（例如 `warm_light.mp3`）放進 `assets/bgm/`，再把 `BGM_ALIAS` 裡那一行刪掉就好。

**檔案大小**：`spring_wind.mp3` 是 320kbps、7MB，比其他兩首大一倍多。網頁遊戲用 **128kbps** 就夠（同一首約 2.8MB），聽感幾乎沒差但載入快很多。線上轉檔工具搜尋「mp3 compressor」就有，轉完覆蓋同一個檔名即可。

**自動播放**：瀏覽器規定使用者還沒點過畫面就不准放音樂，所以**第一次點擊之後音樂才會進來**，這是正常的，不是壞掉。

如果音樂沒聲音，在瀏覽器按 F12 打開主控台，輸入 `Game.audioState()`，會顯示：

| 看到什麼 | 意思 |
|---|---|
| `loaded: false` | 這一幕的劇本沒有指定音樂 |
| `error: 4` | 找不到檔案，檢查檔名（注意副檔名有沒有重複） |
| `paused: true` | 被靜音了，或還沒點過畫面 |
| `readyState: 4, paused: false` | 正常播放中 |

## 給維護者的備忘

- `tools/*.ps1` 含中文註解，**必須存成 UTF-8 with BOM**。Windows PowerShell 5.1 遇到沒有 BOM 的檔案會用系統 ANSI codepage 去讀，中文會變亂碼並造成語法錯誤。
- 同理，**不要**用 `Get-Content` / `Set-Content` 去改這個專案裡的 UTF-8 文字檔（README.md、story.js、*.css、*.js），會整份變成亂碼。用支援 UTF-8 的編輯器，或 `[System.IO.File]::ReadAllText($path, [System.Text.Encoding]::UTF8)`。
